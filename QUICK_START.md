# 🎮 How to Play PyCraft v1.0

## ⚡ Quick Start (Easiest Way!)

1. **Double-click `PLAY.bat`** 
2. Wait for auto-install (first time only)
3. Launcher opens in your browser
4. Click **"PLAY SINGLEPLAYER"**
5. Have fun! 🎉

That's it! No manual setup needed.

---

## 📋 What PLAY.bat Does

- ✅ Auto-installs Python dependencies (pygame, streamlit)
- ✅ Launches the game launcher automatically
- ✅ Opens in your web browser
- ✅ One-click setup - perfect for beginners!

---

## 🎯 First-Time Setup (Automatic)

When you first run `PLAY.bat`:
1. Python checks for required packages
2. Installs pygame and streamlit (1-2 minutes)
3. Launches the PyCraft Launcher
4. You're ready to play!

**Next time**: Everything is already installed, so it launches instantly!

## 🆘 Troubleshooting

### PLAY.bat doesn't work?
**Try manual launch:**
```bash
python install_and_play.py
```

### "Python not found" error?
- Download Python 3.8+ from [python.org](https://python.org)
- ✅ Check "Add Python to PATH" during installation

### Game won't start?
1. Make sure all files are in the same folder
2. Run `python install_and_play.py` manually
3. Check that you have internet (for first-time install)
